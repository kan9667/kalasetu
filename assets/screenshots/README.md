# Project Screenshots & Prototype Visuals — KalaSetu

This folder contains high-resolution screenshots and visual walkthroughs of the KalaSetu mobile application and AI multimodal pipeline for the Smart India Hackathon 2026 submission.

| Filename | Screen / Workflow | Description |
|---|---|---|
| `01-splash-and-auth.png` | Splash & Sign-In | Clean artisan onboarding with phone number authentication and bilingual language selection. |
